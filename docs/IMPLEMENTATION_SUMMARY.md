## 🎨 Design System Highlights

### Color Palette
- **Imperial Gold**: #C4A35A (Primary)
- **Deep Navy**: hsl(222, 47%, 6%) (Background)
- **Imperial Red**: hsl(0, 72%, 51%) (Accent)
- **Jade Green**: hsl(160, 45%, 35%) (Success)
- **Bronze**: hsl(25, 60%, 40%) (Light mode)
- **Ivory**: hsl(43, 30%, 92%) (Light mode bg)

### Typography
- **Headings**: Playfair Display (serif)
- **Body**: Inter / Be Vietnam Pro (sans-serif)
- **Line Height**: 1.8 (Vietnamese optimized)
- **Format**: Self-hosted woff2 with unicode-range

### Visual Effects
- **11 Animations**: fadeInUp, glow-pulse, float, aurora, etc.
- **6 Patterns**: van-may, thuy-ba, dots, grid, diagonal, hexagon
- **Glass Morphism**: backdrop-filter blur
- **Gradients**: Multi-layer gold gradients
